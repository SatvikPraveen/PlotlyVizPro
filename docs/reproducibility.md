# Reproducibility

## Datasets

All bundled data are synthetic and generated by `plotlyvizpro.datasets.generate_all(seed=42)`
from a single `numpy.random.Generator`. `datasets/manifest.json` records, per file,
the SHA-256, byte size, row count, columns and description. `plotlyvizpro.data.load`
verifies the digest before parsing and raises `IntegrityError` on mismatch.

```bash
plotlyvizpro generate-data --seed 42    # regenerates byte-identical CSVs + manifest
plotlyvizpro verify-data                # exit 1 on any mismatch
```

## Figures

`export.save_figure(fig, stem, formats=...)` attaches a `Provenance` record to
`fig.layout.meta["provenance"]` (so it survives `to_json`/`from_json`) and
writes `<stem>.provenance.json` alongside the outputs:

```json
{
  "created_utc": "2026-09-27T04:12:03+00:00",
  "plotlyvizpro": "2.0.0",
  "python": "3.12.6",
  "platform": "macOS-15.6-arm64-arm-64bit",
  "packages": {"plotly": "7.1.0", "pandas": "3.0.6", "numpy": "2.5.3", "scipy": "1.18.1", "kaleido": "1.4.0"},
  "git_commit": "3076b92",
  "inputs": {"superstore": "c0ffee…"},
  "parameters": {"window": 10},
  "random_seed": 42
}
```

Register inputs and parameters explicitly when a figure depends on them:

```python
from plotlyvizpro.provenance import Provenance

rec = Provenance(random_seed=42, parameters={"frac": 0.2}).add_input("superstore", df)
pvp.save_figure(fig, "fig1", provenance=rec)
```

`git_commit` carries a `-dirty` suffix when the working tree has uncommitted changes.

## Environment

- `pyproject.toml` pins lower bounds only; `requirements*.txt` defer to the
  extras. For a frozen environment use `pip freeze > constraints.txt` and
  `pip install -c constraints.txt -e .`.
- The Docker image builds from `python:3.12-slim` and installs `.[all]`.
- CI runs the test matrix on Python 3.10-3.13 and three operating systems,
  executes every notebook, and renders images with kaleido, so the numbers in
  the docs are checked on every push.

## Randomness

Every function that draws random numbers takes `seed` (int or `Generator`) and
uses `numpy.random.default_rng`; nothing touches the legacy global RNG.
